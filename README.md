# TORNADO CLIENT

Клиент для Minecraft 1.21.11 (Fabric): два меню, 98 функций, скины мечей, хитсаунды.

**Сайт:** https://magomed421.github.io/tornadoclient/
**Скачать:** [TornadoClient.zip](https://github.com/magomed421/tornadoclient/releases/latest/download/TornadoClient.zip) — клиент + Fabric API + Sodium, Lithium, FerriteCore.

Установка: поставь [Fabric Loader](https://fabricmc.net/use/installer/) для 1.21.11, скопируй всё из папки `mods` архива в `.minecraft\mods`, запусти профиль fabric-loader-1.21.11. Меню — Правый Shift.

Поддержать: https://www.donationalerts.com/r/magomed653
